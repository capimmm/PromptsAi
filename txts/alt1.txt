PERSONA E DIRETRIZES GERAIS
Assuma o papel de um Engenheiro Principal de UI/UX da Roblox. Sua missão é escrever o código Luau completo (LocalScript + Módulos) para construir, programaticamente, uma interface de usuário idêntica à descrição visual abaixo. O estilo é "Arcade Retrô Moderno": cores saturadas, gradientes vibrantes, bordas grossas (cartoon), cantos arredondados e animações "juicy" (satisfatórias e responsivas).

1. ESTRUTURA DE HIERARQUIA E LAYOUT (MUITO IMPORTANTE)
Tudo deve ser filho de um ScreenGui chamado ArcadeUI (IgnoreGuiInset = true).
Crie um Frame central chamado MainContainer (Size: UDim2.fromScale(0.8, 0.7), AnchorPoint: 0.5, 0.5, Position: 0.5, 0.5). Adicione UIAspectRatioConstraint (AspectRatio: 1.6) para manter a proporção em qualquer tela.

Divida o MainContainer em 3 áreas usando Frame:

LeftPanel (Size: 0.45, 1, Position: 0, 0): O visualizador principal.

RightPanel (Size: 0.5, 0.65, Position: 0.5, 0): A grade de botões/itens.

BottomBar (Size: 1, 0.25, Position: 0, 0.75): A barra de navegação.

3. ANIMAÇÕES E OTIMIZAÇÃO (UI JUICE)

Biblioteca Recomendada: Estruture o código usando o padrão do Trove (ou Maid) para limpar conexões de eventos e Tweens mortos. Se não puder usar módulos externos, escreva uma classe Cleaner simples.

Hover Effect: No MouseEnter, use TweenService (TweenInfo.new(0.2, Enum.EasingStyle.Back, Enum.EasingDirection.Out)). Altere Size para 1.05 (baseado no tamanho original) e mude a cor do UIStroke para um branco mais brilhante. No MouseLeave, retorne ao normal.

Click Effect: No MouseButton1Down, encolha para 0.95 usando Enum.EasingStyle.Quad. No MouseButton1Up, retorne para 1.05 (se o mouse ainda estiver em cima) ou 1.0.

Abertura da UI: Ao iniciar, coloque o MainContainer invisível e com tamanho 0,0. Use TweenService para animar a Size para 0.8, 0.7 com EasingStyle.Quint e a BackgroundTransparency dos elementos.

Otimização: NUNCA crie Tweens dentro do loop RenderStepped. Use eventos de input. Use UIGradient com moderação e evite aplicar gradientes em textos com TextStroke (isso causa lag no renderizador).
